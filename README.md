# Bofrid – hyr och hyr ut bostad i Sverige

**[Bofrid](https://bofrid.se)** är en svensk marknadsplats för hyresbostäder. Hitta lägenhet, rum eller hus att hyra – eller hyr ut din bostad – direkt mellan hyresgäst och hyresvärd.

- 🏠 Hyr bostad: lägenheter, rum, villor och andrahandsboenden i hela Sverige
- 🔑 Hyr ut: lägg upp din bostad och få ansökningar från verifierade hyresgäster
- 📍 Stockholm, Göteborg, Malmö, Uppsala och fler städer

👉 **https://bofrid.se**
